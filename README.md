#  Pizza Runner – SQL Data Analysis

## Project Overview
This project focuses on analysing Pizza Runner's business data using SQL Server. The goal was to explore customer orders, pizza preferences, runner performance, delivery efficiency, ingredient usage, and revenue.

The analysis is based on the Pizza Runner case study from the **8 Week SQL Challenge by Danny Ma**.

## Tools & Technologies
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- SQL (T-SQL)

## Database Tables
The project uses the following tables:

- `runners` – Runner registration details.
- `customer_orders` – Customer orders and pizza customisations.
- `runner_orders` – Delivery and runner information.
- `pizza_names` – Available pizza types.
- `pizza_recipes` – Standard pizza ingredients.
- `pizza_toppings` – Pizza topping details.
- `runner_ratings` – Additional customer ratings for runners.

## Analysis Performed

### 1. Pizza Metrics
- Total pizzas ordered.
- Unique customer orders.
- Successful deliveries.
- Most popular pizza types.
- Customer pizza preferences.
- Ordering patterns by hour and day.

### 2. Runner & Customer Experience
- Weekly runner registrations.
- Average pickup preparation time.
- Relationship between pizza quantity and preparation time.
- Average delivery distance.
- Delivery duration.
- Runner delivery speeds.
- Successful delivery percentages.

### 3. Ingredient Optimisation
- Standard ingredients for each pizza.
- Most commonly added extras and exclusions.
- Generating customised pizza order descriptions.
- Calculating ingredient quantities used in delivered pizzas.

### 4. Pricing & Ratings
- Total pizza revenue.
- Revenue generated from additional extras.
- Designing a runner ratings table.
- Combining customer, order, runner and delivery information.
- Calculating delivery costs and estimated net profit.

### 5. Bonus Analysis
- Expanding the pizza menu.
- Adding a new Supreme pizza to the existing database.

## SQL Skills Demonstrated
- SELECT statements
- JOINs
- GROUP BY and ORDER BY
- Aggregate functions (COUNT, SUM, AVG, MIN, MAX)
- CASE statements
- Common Table Expressions (CTEs)
- Data cleaning and transformation
- Date and time functions
- String manipulation
- Table creation and modification
- Data analysis using SQL

## Project Objective
The main objective was to develop practical SQL skills while using business data to answer real-world questions about customer behaviour, restaurant operations, delivery performance and profitability.
